Installation

Get CodeTracker Pro running on Chrome in under 2 minutes.

01

Download the ZIP

Grab the latest release from GitHub. It's a small file, downloads instantly.

Download Latest
02

Extract the files

Right-click the downloaded ZIP and select Extract All. Remember where you extracted it, you'll need this in step 5.

03

Open Chrome Extensions

Paste this URL in Chrome address bar (or click to copy):

chrome://extensions/
04

Enable Developer Mode

Look at the top-right corner of the Extensions page. Toggle ON the Developer mode switch.

05

Load Unpacked

Click the Load Unpacked button that appears. Select the extracted folder from Step 2.

06

Pin the extension

Click the puzzle icon in Chrome toolbar. Find CodeTracker Pro and pin it so it's always visible.

You're all set!

Open LeetCode or HackerRank and start solving. The extension will track everything automatically.

Common Issues

Extension not detecting my solves?

Close all LeetCode/HackerRank tabs and open a fresh one. Extension only counts on Submit button (not Run Code).

Notifications not working?

Enable Chrome notifications in Windows Settings and check reminder time is set correctly in extension Settings tab.

Data got reset?

Auto-backup runs every 10 seconds. Data restores automatically if wiped accidentally.

How to uninstall?

Go to chrome://extensions/ and click Remove on CodeTracker Pro. All local data will be cleared.
