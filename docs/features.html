Features

Everything you need to stay consistent. Nothing you don't.

🎯

Platform Goals

Set separate daily targets for LeetCode and HackerRank. Track weekly and monthly progress with visual rings.

🔥

Streak System

Build consistency with smart streak tracking. 2-day grace period so one bad day doesn't destroy progress.

📊

Activity Heatmap

GitHub-style 28-day heatmap visualization. See your consistency at a glance.

⏰

Custom Reminders

Set exact times like 6 AM or 9 PM. Add multiple reminders. Never forget to code again.

🤖

Auto Detection

Automatically counts problems when you click Submit. No manual logging. Zero friction.

🏅

Achievements

8 unlockable badges. From first solve to century club. Gamified progress.

😂

Fun Messages

60+ Hinglish motivational quotes. Roasts when you're lazy. Celebrates when you win.

🌙

Dark Mode UI

Minimal, focused design. Apple and Linear inspired. Easy on the eyes for long sessions.

🔒

Privacy First

100% local storage. Zero data sent externally. No tracking. No analytics. Your data stays yours.
