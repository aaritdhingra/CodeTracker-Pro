Installation

Install in 2 Minutes

Simple steps. No account. No configuration.

1

📥 Download the ZIP

Click the download button and save the ZIP file to your computer.

⬇️ Download Latest Release
2

📂 Extract the Files

Right-click the ZIP file and select "Extract All". Remember the folder location.

3

🌐 Open Chrome Extensions

Paste this URL in your Chrome address bar (click to copy):

chrome://extensions/
4

🔧 Enable Developer Mode

Look at the top-right corner. Toggle ON the "Developer mode" switch.

5

📁 Load the Extension

Click "Load unpacked" button. Select the extracted folder from Step 2.

6

📌 Pin It!

Click the puzzle icon 🧩 in Chrome toolbar. Pin CodeTracker Pro. Done!
