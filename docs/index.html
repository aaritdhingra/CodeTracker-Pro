Installation Guide

Follow each step carefully. Takes 2 minutes.

1

📥 Download the ZIP

Click the download button above. A file named CodeTracker-Pro-v1.0.0.zip will be saved to your Downloads folder.

2

📂 Extract the ZIP

Right-click the downloaded ZIP file and select "Extract All" (Windows) or double-click (Mac). Remember the folder location.

3

🌐 Open Chrome Extensions

Copy this URL and paste in Chrome's address bar (or click to copy):

chrome://extensions/ 📋
4

🔧 Enable Developer Mode

Look at the top-right corner of the Extensions page. Toggle ON the "Developer mode" switch.

5

📁 Load the Extension

Click the "Load unpacked" button (appears after enabling Developer mode). A file browser will open. Select the extracted folder from Step 2.

6

📌 Pin the Extension

Click the puzzle icon 🧩 in Chrome's toolbar (top-right). Find CodeTracker Pro and click the pin 📌 icon next to it.

🎉

You're All Set!

CodeTracker Pro is now installed. Click the extension icon to get started.
