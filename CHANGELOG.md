# Changelog

## v1.2.0 - 2026-07-30

### Multi-Platform Edition

**New Platforms Added (10+ total):**
- Code360 (Coding Ninjas)
- GeeksforGeeks
- CodeChef
- Codeforces
- AtCoder
- InterviewBit
- HackerEarth
- Codewars

**New Features:**
- Dedicated Platforms tab in extension
- Individual toggle for each platform (enable/disable)
- Common goal system for other platforms
- Platform breakdown in Stats page
- Success detection for all platforms
- Random funny Hinglish messages for each platform
- Platform-specific welcome toasts

**Goals System:**
- LeetCode: Individual daily goal
- HackerRank: Individual daily goal
- Other Platforms: Combined common goal

**UI Updates:**
- New Platforms tab with all 10 platforms
- Colored avatars for each platform
- Enable/disable toggles
- Live per-platform stats
- Toggle all button for bulk actions

**Detection:**
- Submit only counts when verdict is Successful
- 5 minute cooldown per problem
- Smart button detection (skips Run/Compile/Test)
- Wrong answers not counted

**Streak System:**
- All 10 platforms count towards streak
- Solve on any platform to maintain streak
- Common heatmap across platforms
